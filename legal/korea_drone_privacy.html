개인정보처리방침

시행일: 2026년 11월 6일 · 최종 수정: 2026-11-06

이 문서는 인스타그램 계정 korea__drone의 운영자가 본인의 영상을 본인의 YouTube 채널에 올리기 위해 직접 만들어 쓰는 업로드 도구(이하 "이 도구")의 개인정보 처리 방침입니다. 이 도구는 일반 이용자에게 제공되지 않으며, 운영자 한 명만 사용합니다.

1. 이 도구가 하는 일

  • 운영자의 컴퓨터에 저장된 영상 파일(드론 관련 소식 영상)을, 운영자가 허용한 운영자 본인의 YouTube 채널에 업로드합니다.
  • 이를 위해 Google 계정 권한 중 YouTube 영상 업로드 권한(youtube.upload) 하나만 요청합니다.

2. 수집·저장하는 정보

  • 이 도구는 다른 이용자의 개인정보를 수집하지 않습니다. 시청자, 댓글 작성자, 구독자의 정보를 읽거나 저장하지 않습니다.
  • 운영자가 Google 로그인을 허용하면 발급되는 접근 권한 정보(토큰)가 운영자의 개인 컴퓨터에만 저장됩니다. 외부 서버나 공개 저장소로 보내지 않습니다.
  • 업로드한 영상의 제목, 설명, 공개 범위는 운영자가 정한 값이며 YouTube에 게시됩니다.

3. 이용·제공

  • Google 사용자 데이터는 위 1번의 업로드 기능 외 다른 목적으로 사용하지 않습니다.
  • Google 사용자 데이터를 판매하거나 광고 목적으로 사용하거나 제3자에게 제공하지 않습니다.
  • 이 도구의 Google API 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 보유 기간과 권한 철회

  • 접근 권한 정보는 운영자가 삭제하거나 권한을 철회할 때까지 운영자의 컴퓨터에만 보관됩니다.
  • 운영자는 언제든지 Google 계정의 서드 파티 연결 관리 페이지에서 이 도구의 접근을 철회할 수 있고, 컴퓨터에 저장된 토큰 파일을 삭제할 수 있습니다.

English summary

This tool is a personal automation script used only by the operator of the Instagram account korea__drone to upload the operator's own videos to the operator's own YouTube channel. It requests only the youtube.upload scope. It does not collect, store or share any other person's data. The OAuth token is stored only on the operator's own computer and is never sent to any other server. Google user data is used solely to upload the operator's videos, is not sold or used for advertising, and handling follows the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. Contact: Instagram DM @korea__drone.
